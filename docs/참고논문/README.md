## 특히 중요한 것

[`04_타겟지표/08_target_metrics.md`](04_타겟지표/08_target_metrics.md)

README가 "Val R² 0.09가 문제의 천장에 근접"이라고 서술하는 근거입니다.
선행 연구에서도 구속→ERA 예측은 R² 0.05~0.08 수준이고,
최고 지표 SIERA조차 다음 시즌 ERA의 20%만 설명합니다.

경기 단위 + 초반 15구라는 더 어려운 조건에서 나온 값이라
낮은 R²가 모델 실패가 아니라는 판단의 근거가 됩니다.
